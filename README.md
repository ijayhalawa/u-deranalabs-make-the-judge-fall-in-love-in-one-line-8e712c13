## The entry

`main.py` (Python 3, standard library only, no network) writes a single line of at most 240 characters to `/output/entry.txt`:

> He folds my side of the blanket back every night, even when I'm already asleep, even when I'm not coming home.

## Run

```sh
python3 main.py
```

Deterministic: two runs produce byte-identical output.
